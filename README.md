# عبقريو
## منصة تعليمية ذكية للأطفال

---

## عن المشروع

**عبقرينو** هي منصة تعليمية تفاعلية ذكية موجهة للأطفال من عمر ٦ إلى ١٢ سنة.

تهدف المنصة إلى دمج **التعليم مع الترفيه** من خلال:
- دروس تفاعلية وفيديوهات تعليمية.
- ألعاب تعليمية (مطابقة، ذاكرة، واقع معزز).
- ذكاء اصطناعي للمحادثة والتوجيه.
- نظام متابعة للإنجازات والمكافآت.
- دعم لثلاثة أدوار: **طالب، معلم، ولي أمر**.



## أهداف المشروع

- تصميم تجربة مستخدم سلسة ومناسبة للأطفال.
- تطوير واجهة جذابة وآمنة تحفز الطفل على التعلم.
- تمكين المعلمين من إدارة المحتوى بسهولة.
- إشراك أولياء الأمور في متابعة تقدم أبنائهم.



## الأدوار الرئيسية

| الدور | الوظيفة |
| **طالب** | استعراض الكورسات، مشاهدة الدروس، حل الاختبارات، الألعاب، جمع النقاط والمكافآت |
| **معلم** | إضافة وتعديل الكورسات والدروس، إنشاء اختبارات، إدارة الطلاب، التقارير |
| **ولي أمر** | متابعة تقدم الطفل، الاطلاع على الكورسات، التواصل مع المعلم |



## الأدوات والتقنيات المستخدمة

| الأداة | الغرض |
